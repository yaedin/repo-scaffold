# Journal

Dated working notes, one file per day: `YYYY-MM-DD.md`.

**Everything volatile belongs here** — what is running, what broke, what you
believe today, what you tried that did not work. `AGENTS.md` and `README.md` stay
durable precisely because this directory absorbs the churn.

This is also where the record of a changed mind lives. When a result is retracted,
the journal entry explaining what killed it is the evidence that you checked, and
it is worth more to a careful reader than the original finding was.

Format:

```markdown
# 2026-08-14

## What I did

## What I found

## What changed my mind

## Next
```
