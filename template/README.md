# Untitled Research Project

A research project. Replace this line via `just init`.

> **Writing this README:** lead with the claim, not the setup. A reader decides in
> fifteen seconds whether to keep going, and what they need in those fifteen
> seconds is *what you found* and *how much to believe it*. The orientation below
> is for people who have already decided to stay.

## In one paragraph

_State the result. What did you test, what did you find, and what is the single
biggest reason to doubt it? Name the effect size and the sample. If the headline
is a null, say so here — a measured null with a stated sensitivity is a finding;
a null presented as an absence of work is not._

## Running it

```bash
uv sync
just verify
```

`uv sync` is the only command that assumes anything about your machine — it
installs Python dependencies *and* the `just` task runner itself, so the repo
behaves identically on macOS, Linux and Windows. Then:

| Command | What it does |
|---|---|
| `just smoke` | End-to-end experiment in under ten seconds. No GPU, no API key, no network. |
| `just test` | Unit tests for the statistics and integrity machinery |
| `just check` | Verifies every path cited in `CLAIMS.md` and `AGENTS.md` still exists, and that no oversized blob is staged |
| `just figures` | Regenerates every committed figure from its source data |
| `just paper` | Renders the Markdown writeup to PDF via Typst. No LaTeX needed. |
| `just verify` | lint + test + smoke + check. Run before committing. |
| `just verify-full` | `verify`, plus `figures` and `paper`. What CI runs. |
| `just wordcount` | Per-section prose word counts. Informational only. |
| `just publish-check` | Licence, citation, figures, paper source, unresolved claims, repo size |

## Layout

| Path | Contents |
|---|---|
| `experiments/` | One directory per experiment: spec.md, run.py, analyze.py, RESULTS.md |
| `src/lab/` | Reusable machinery — paths, seeds, manifests, statistics, integrity checks |
| `figures/` | Committed figures (PDF for the paper, PNG for the web), regenerated on demand |
| `writeup/` | Paper source |
| `docs/journal/` | Dated working notes |

Each experiment's `RESULTS.md` is generated by its `analyze.py` and is the source
of truth for that experiment's numbers. Raw records are gitignored — they are
regenerable from `run.py` plus the recorded seed, and can be large. The derived
`summary.json` and `manifest.json` are committed as the evidence.

Working conventions, and the rules an agent is expected to follow, are in
`AGENTS.md`.

## Known gaps

_Say what you did not do. Unsourced numbers, experiments that were specified but
never run, controls you know are missing. A reader who finds a hole you did not
flag stops trusting everything you did flag._
